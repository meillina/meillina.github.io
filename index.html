Halo, Saya Meillina 👋

Perkenalkan, nama saya Meillina Br Sihotang. Saya merupakan pelajar di SMK Mandiri yang memiliki ketertarikan pada bidang teknologi, khususnya dalam pembuatan dan pengembangan website.

Selama belajar di sekolah, saya mempelajari HTML, CSS, Bootstrap, PHP, dan MySQL. Saya senang mengembangkan kemampuan melalui latihan coding dan membuat berbagai projek sederhana.
