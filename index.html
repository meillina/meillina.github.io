Halo, Saya Meillina 👋

Perkenalkan, nama saya Meillina Br Sihotang. Saya adalah seorang siswa SMK Mandiri dari jurusan Rekayasa Perangkat Lunak (RPL) yang tertarik dengan dunia teknologi dan pembuatan website.

Selama belajar di jurusan RPL, saya mulai mengenal dan mempelajari berbagai teknologi seperti HTML, CSS, Bootstrap, PHP, dan MySQL. Saya senang mencoba hal-hal baru dalam coding dan membuat website sederhana sebagai bagian dari proses belajar saya.

Selain belajar coding, saya juga memiliki beberapa hobi seperti mendengarkan musik, bermain game, dan jalan-jalan. Saya juga sering membantu orang tua berjualan di warung. Dari pengalaman tersebut, saya belajar menjadi pribadi yang lebih mandiri, bertanggung jawab, disiplin, dan menghargai proses.

Melalui portfolio ini, saya ingin memperkenalkan diri sekaligus menunjukkan beberapa hal yang saya pelajari dan kerjakan selama menjadi siswa RPL. 💗

Projek yang saya buat 💕

Website Portfolio

Website ini merupakan portfolio pribadi yang saya buat untuk memperkenalkan diri, menampilkan informasi tentang diri saya, hobi, dan kemampuan yang saya pelajari selama menjadi siswa RPL.

Website ini dibuat dengan tampilan sederhana, menarik, dan responsif agar dapat digunakan pada komputer maupun perangkat lainnya.
